## Projects on Stellar

### [Nirium](https://github.com/M0nsxx/Nirium)

Autonomous AI-agent protocol running on Stellar testnet — SDEX swaps, Soroban vaults with flash loans, ELO reputation, and an on-chain strategy marketplace. My role: **UX/UI Design & visual systems for the frontend** (Next.js 15 + React Three Fiber).

### [VerifyStar](https://github.com/M0nsxx/VerifyStar) · [verify-star.vercel.app](https://verify-star.vercel.app)

Supply-chain transparency platform on Stellar/Soroban — product tokenization as NFTs, QR-based verification, and automated fair-trade payments via smart-contract escrow. Built with Next.js, Freighter wallet, and Soroban smart contracts in Rust.

### [Stellar](https://github.com/M0nsxx/Stellar) · [StellarCodigoFutura](https://github.com/M0nsxx/StellarCodigoFutura)

Learning repos from the "Código Futura con Stellar" course — JavaScript scripts for account creation, payments, balance monitoring, and Soroban contract invocation on Stellar testnet.
